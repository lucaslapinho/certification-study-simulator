# Repository layout

| Path | Contents |
|---|---|
| `source/certification-study-simulator/` | Canonical Skill source, references, schemas, engine, templates, and examples |
| `plugin/.codex-plugin/plugin.json` | Plugin manifest and display metadata |
| `plugin/assets/` | Icon for the plugin listing and `@` picker |
| `tools/package.py` | Build script and checks for the manifest, paths, and assets |
| `tools/demo.py` | Reproducible 10-question mock exam with synthetic responses |
| `tests/` | Automated checks, behavioral prompts, and synthetic fixtures |
| `docs/` | Design decisions, packaging guide, usage examples, and validation |
| `evidence/` | Local outputs from the tests and demo |
| `packages/` | Local artifacts generated by the build script |

The plugin release contains the manifest under `.codex-plugin/`, the icon under `assets/`, and the Skill under `skills/certification-study-simulator/`. The repository contains the development files.
